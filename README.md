# Inspections Database

This repository contains a **relational database project** that models an inspection system using SQL.

> This is an older academic project uploaded for reference. The schema and data model were created as part of a learning exercise.

---

## 🧠 Project Overview

The goal of this database project is to design and implement a relational structure for an inspection workflow. The focus is on correctly modeling entities and their relationships using SQL.

Key concepts include:
- Entities such as inspectors, inspection records, facilities, results
- Proper use of primary keys and foreign keys
- One-to-many and many-to-many relationships where appropriate
- Sample data for testing queries and validating constraints

This project explores data modelling rather than application development.

## 🧱 Database Design

The database is structured to support:
- Inspectors and their assignments
- Places or facilities subject to inspection
- Inspection events, results, and timestamps
- Links between inspectors and inspected objects

Referential integrity is enforced via foreign key constraints.
